## Project Description
We chose this project to address the growing need for proactive safety regarding Crime in the US and to come up with unique and innovative solutions — transforming crime data into actionable alerts and duck-themed gamification. By blending serious crime prevention with lighthearted duck motifs, we've created an app that not only keeps users safer but also builds community awareness through a memorable, approachable interface. 

### Key Features:
- **Real-time Risk Map:** Displays a heatmap of various risks in the user's area.
- **Personalized Alerts:** User or parents/guardians ( for duckling users )can receive notifications about relevant threats in their location.
- **Emergency Resources:** Provides a list of emergency contacts and shelters.
- **SOS Button:** An emergency button that is customizable to different alarms.
- **One stop Button:** To call emergency services and give location to trusted contacts in a single tap.
- **Quack safety Academy:** New articles and Tips about safety from verified sources in a fun manner.

## Technologies Used
- **Frontend:** Flutter and Firebase
- **Backend:** Flask (Python) / Node.js (Express)
- **Database:** Firebase / PostgreSQL
- **AI/NLP:** OpenAI API / LangChain
- **APIs:** Google Maps API (visualization), Twilio (alerts via SMS)


## Usecases
- Users can view real-time risk updates.
- Interact with the AI chatbot for risk-related queries.
- Subscribe to alerts for specific risk categories.
- Access emergency resources when needed.
